One line of weather for Updraft Falls, a city that isn't — where the snow
falls up. Written for the make.fun bounty
[Charm the Commuter: Forecast a City That Isn't](https://make.fun/c/u-golden-heron-44-charm-the-commuter-forecast-a-city-4018259e?ref=h379tqrk).

`main.py` writes a single 137-character forecast line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

> Updraft Falls: snow falling up, 3°C, flakes landing on rooftops first — catch one on the stairs, the 7:40 leaves on time, sky permitting.
